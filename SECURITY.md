# Security policy

## Supported versions

This project is an experimental alpha. Only the current default branch is
considered for security fixes; there is no supported binary or package release
channel yet.

## Reporting a vulnerability

Do not disclose sensitive vulnerability details in a public issue, discussion,
or pull request.

If GitHub's private vulnerability reporting is enabled for the repository, use
the **Report a vulnerability** action on the repository's Security page. If
that action is not available, do not publish the sensitive details; wait until
the maintainers provide a verified private reporting channel.

Include the affected revision, a minimal reproduction, impact, and any known
mitigation. Reports should avoid real credentials, private source, or unrelated
personal data.

Ordinary non-sensitive correctness bugs may be reported through the public
issue tracker after the repository is public.
