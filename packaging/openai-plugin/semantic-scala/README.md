# semantic-scala OpenAI/Codex candidate

This source template is assembled with the exact published Alpha-3 MCPB. The
generated local candidate contains the canonical skill and a bundled local
stdio MCP server. It is limited to Linux x86_64 with compatible GNU libc and
system zlib and requires no host Java.

This is a locally validated candidate, not a public directory listing. OpenAI
requires a stable public HTTPS MCP endpoint for public MCP submission; this
package does not claim or provide one.
